# About this project
A GCSE maths practice website (like excelexercises.com but for GCSE maths).
Students answer questions, get instant feedback, hints and worked solutions.

# How to help me
- Explain concepts in plain English before showing code
- Give me hints first and let me try. Only write full code if I ask
- Keep code simple: plain HTML, CSS and JavaScript only, no frameworks or libraries yet
- When I get an error, explain what caused it, not just the fix
- Add short comments to any code you write
- Before changing my files, tell me what you're about to change and why
